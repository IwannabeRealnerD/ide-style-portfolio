## Getting started in your local environment

- To get started with this project, you need to clone the reapository and install the dependency.

### Environment Setup

- nodejs - 20.10.0
- pnpm - 9.9.0
  ```sh
  corepack prepare pnpm@9.9.0 --activate
  ```

### How to Deploy Dev Server

1. Clone repository
   ```sh
   git clone https://github.com/IwannabeRealnerD/ide-style-portfolio.git
   ```
2. Install pnpm dependency
   ```sh
   pnpm install --frozen-lockfile
   ```
3. Start Dev Server
   ```sh
   pnpm dev
   ```
